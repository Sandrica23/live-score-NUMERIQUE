# Coupe des Filieres - Live Score

## Presentation du projet

Application web permettant d'afficher automatiquement
le classement de la Coupe des Filieres.

## Membres de l'equipe

- Lead : gestion du projet et integration
- Dev A : gestion des donnees
- Dev B : calcul du classement
- Dev C : design du site

## Comment ouvrir le site

Ouvrir le fichier index.html dans un navigateur web.

## Technologies utilisees

- HTML
- CSS
- JavaScript
- Git et GitHub# Coupe des Filieres - Live Score
